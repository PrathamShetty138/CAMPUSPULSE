Problem Statement
Challenges in Traditional
Feedback Systems
📋

Manual Processing

Feedback collected on paper or basic forms requires manual reading and interpretation, which is time-consuming and error-prone.

⏳

Delayed Insights

No real-time analysis means institutions react too late to student concerns, missing the opportunity for timely improvements.

📉

No Sentiment Detection

Traditional systems lack the ability to automatically detect whether feedback is positive, neutral, or negative.

🔒

Lack of Role-based Access

No clear separation between student and admin views leads to privacy concerns and unstructured data management.

Objectives
What CampusPulse Aims to Achieve
01

Provide an easy-to-use platform for students to submit structured feedback on teaching, facilities, and curriculum.

02

Automatically classify feedback sentiment as Positive, Neutral, or Negative using a rule-based AI engine.

03

Deliver real-time analytics and interactive charts to administrators for data-driven academic decision-making.

04

Generate AI-inspired insights and actionable recommendations to improve academic quality continuously.

05

Ensure secure, role-based access with separate Student and Admin portals to maintain data privacy.

Implementation — Technology Stack
🌐

HTML

Semantic structure for all pages including forms, dashboards, and navigation

🎨

CSS

Custom styling with animations, gradients, responsive layouts, and dark theme UI

⚡

JavaScript

Core logic for sentiment analysis, chart rendering, and dynamic UI interactions

🧠

Sentiment Engine

Rule-based NLP logic with negation handling and keyword scoring (~95% accuracy)

💾

localStorage

Client-side data persistence — no backend or database required

📊

Canvas API

Custom pie charts and bar graphs rendered natively without external libraries

Project Demo — Key Features

🎓 Student Portal

  • Sign up / Sign in with USN
  • Submit feedback with category & rating
  • View submission history
  • Manage personal profile

🛡️ Admin Dashboard

  • Real-time sentiment overview
  • Pie chart & rating distribution
  • Category & subject-wise analysis
  • AI-generated recommendations

🤖 Sentiment Analysis

  • Positive / Neutral / Negative classification
  • Negation handling (e.g. "not good")
  • Keyword scoring with context
  • ~95% classification accuracy

📤 Reports & Export

  • Export all feedback as CSV
  • Summary statistics included
  • Filter by sentiment type
  • Refresh dashboard in real-time
